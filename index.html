🔒 Política de Privacidad

Última actualización: Mayo 2026 · Ley 25.326 de Protección de Datos Personales (Argentina)

1. Responsable del tratamiento de datos

2. Datos que recolectamos

Al realizar una compra o consulta, podemos recopilar los siguientes datos personales:

  • Nombre y apellido
  • Dirección de correo electrónico
  • Número de teléfono / WhatsApp (solo pedidos mayoristas)
  • Dirección de entrega (solo si elegís envío a domicilio)
  • Datos de pago: procesados exclusivamente por Mercado Pago; Los Angelitos no almacena números de tarjeta ni datos financieros.

3. Finalidad del tratamiento

Los datos personales recolectados son utilizados exclusivamente para:

  • Procesar y gestionar tu pedido.
  • Coordinar el envío o retiro del producto.
  • Enviarte confirmaciones y notificaciones relacionadas con tu compra.
  • Dar cumplimiento a obligaciones legales y fiscales.

Los datos no serán cedidos ni comercializados a terceros sin tu consentimiento expreso, salvo exigencia legal.

4. Almacenamiento y seguridad

Los datos de pedidos se almacenan en Google Sheets con acceso restringido al titular. Los pagos con tarjeta son procesados por Mercado Pago, que cumple con estándares PCI-DSS. Utilizamos conexiones HTTPS para proteger la transmisión de datos.

5. Plazo de conservación

Los datos se conservan durante el tiempo necesario para completar la relación comercial y cumplir con obligaciones legales impositivas (mínimo 5 años según legislación fiscal argentina), tras lo cual serán eliminados o anonimizados.

  • Acceso: conocer qué datos tuyos tenemos registrados.
  • Rectificación: corregir datos inexactos o incompletos.
  • Supresión: solicitar la eliminación de tus datos cuando ya no sean necesarios.
  • Oposición: oponerte al tratamiento de tus datos en determinadas circunstancias.

Mercado Pago — Checkout Pro

Para activar el pago con tarjeta necesitás crear un Worker gratuito en Cloudflare que actúa de puente seguro con la API de MP.

⚠️
Worker no configurado
El pago con tarjeta está deshabilitado hasta que configures el Worker.
📋 Pasos para activar
1
Crear cuenta en Cloudflare
Entrá a workers.cloudflare.com → creá una cuenta gratis → "Create a Worker"
2
Copiar el código del Worker
Hacé clic en "Copiar código" y pegalo en el editor de Cloudflare
✓ Copiado
3
Agregar las 4 variables de entorno
En Cloudflare → Settings → Variables → New variable. Agregá estas 4:
MP_ACCESS_TOKEN → Tu Access Token de producción de MP (empieza con APP_USR-)
RESEND_API_KEY → Tu API Key de resend.com (para enviar mails automáticos)
FROM_EMAIL → Email remitente verificado en Resend. Ej: pedidos@losangelito.com.ar
MP_WEBHOOK_SECRET → (Opcional) Clave secreta del webhook de MP
4
Pegar la URL del Worker acá
Después de publicar el Worker, Cloudflare te da una URL tipo https://mi-worker.workers.dev

Emails automáticos — Worker de Resend

Configurá el Worker dedicado para que los clientes y vos reciban emails automáticos al hacer un pedido. Es un Worker de Cloudflare separado al de Mercado Pago.

⚠️
Worker no configurado
Sin esto los emails de confirmación de pedido no se envían.
📋 Pasos para activar
1
Crear cuenta en Resend
Entrá a resend.com → creá una cuenta gratis → API Keys → Create API Key → copiá la key (empieza con re_)
2
Crear Worker en Cloudflare
Entrá a dash.cloudflare.com → Workers & Pages → Create application → Create Worker → llamalo losangelitos-email
Pegá el código del archivo email-worker.js que descargaste junto con este HTML y hacé clic en Deploy.
3
Agregar la variable de entorno
En Cloudflare → Settings → Variables → New variable (marcar "Encrypt"):
RESEND_API_KEY → tu API Key de Resend (empieza con re_)
4
Pegar la URL del Worker acá abajo y guardar
La URL es tipo https://losangelitos-email.tuuser.workers.dev
